# HISTORY OF INDIAN CURRENCY — An Interactive 2,500-Year Numismatic Museum

[![Deploy to GitHub Pages](https://github.com/mnk17arts/history-of-indian-currency/actions/workflows/deploy.yml/badge.svg)](https://github.com/mnk17arts/history-of-indian-currency/actions/workflows/deploy.yml)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-mnk17arts.github.io-emerald?style=flat&logo=firefox)](https://mnk17arts.github.io/history-of-indian-currency/)
[![License: MIT](https://img.shields.io/badge/License-MIT-amber.svg)](https://opensource.org/licenses/MIT)

An interactive numismatic exhibition tracing the evolution of Indian currency across 2,500 years — from 6th century BCE silver punch-marked coins (Karshapanas) of Emperor Ashoka, to Sher Shah Suri’s original 1542 silver *Rupiya*, colonial British India coinage, modern high-security banknotes, and the sovereign cryptographic Digital Rupee (e₹ - CBDC).

---

## 🏛️ Key Features

- **Interactive 3D Specimen Stage**:
  - Full mouse-driven 3D perspective rotation with dynamic specular highlight sheen.
  - Smooth double-sided 3D card/coin flipping between obverse (front) and reverse (back).
  - "Hold to Light" Watermark Backlight simulator showing translucent embedded watermarks and electrotype numerals.
- **365nm UV Blacklight Mode**:
  - Transforms the virtual exhibition into an ultraviolet currency inspection darkroom.
  - Illuminates fluorescent optical fibres, glowing security threads, and neon-reactive serial numbering.
- **4x–8x Precision Magnifying Loupe**:
  - Interactive circular brass loupe with crosshair reticle for inspecting microprinting (`RBI` & `भारत`), intaglio raised ink ridges, and blind-assist bleed lines.
- **Purchasing Power Time Machine**:
  - Interactive historical slider spanning 1540 to 2026.
  - Compares what 1 Rupee bought across eras (from 64 kg of wheat under Sher Shah Suri to a piece of candy today).
- **₹10 Denomination Evolution**:
  - Multi-generational visual chronicle of India’s most redesigned banknote across 7 decades.
- **Side-by-Side Comparison Mode**:
  - Contrast any two historical currency pieces side-by-side to observe design philosophy shifts across centuries.
- **Zero-Asset Procedural Web Audio**:
  - Synthesizes crisp paper note rustle, clinking silver coins, mechanical loupe clicks, and electric UV lamp snaps using the W3C Web Audio API without bulky audio assets.

## 📜 Research & Public Domain Rights Framework

All visual specimens and factual data are curated from open, verifiable institutional sources:
- **Reserve Bank of India Monetary Museum & FAQs**: Core architectural data, security features, dates, and dimensions.
- **Wikimedia Commons Numismatic Repositories**: High-resolution specimens licensed under the **Government Open Data License (GODL-India)** and public-domain provisions (coins from ancient/medieval/colonial eras and Indian works published before 1964 under Section 25 of the Indian Copyright Act 1957).

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript
- **Bundler & Tooling**: Vite, vanilla modern CSS (custom tokens, obsidian glassmorphism, responsive CSS grid)
- **Icons**: Lucide React
- **Audio Engine**: Synthesized Procedural Web Audio API
- **Deployment**: Automated GitHub Pages CI/CD via GitHub Actions

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/mnk17arts/history-of-indian-currency.git
cd history-of-indian-currency

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
